# Primary Jest report fixtures for B2 / D2

The 15 JSON reports are the supplied public review evidence from
`dev-pr6-v1/logs/jest27`, `logs/jest29`, and `logs/jest29-tsjest`. They were
generated by Jest 27.5.1, Jest 29.7.0, and the reviewed Jest 29.7.0 ts-jest
configuration against synthetic source probes. The matching source snippets
are copied from the supplied public `probes/` directory. No product code is
executed by the fixture tests.

`provenance.json` records each original SHA-256, normalized fixture SHA-256,
and source-relative path. The only report transformation replaces the original
common scratch `lead` directory with `/__jest_fixture__`. Test IDs, matcher
details, declaration locations, frame names, frame order and source line/column
numbers are unchanged. Tests relocate that root into their own temporary
repository so normal source-file binding still runs.

The runner adds `--testLocationInResults`. These real location reports show a
declaration point, not callback scope: rejecting failures before that line
would also reject helpers declared above a test. D2 therefore accepts a concrete
assertion with a complete repository source frame when the known Circus hook
frame is absent. An indistinguishable async hook can pass under this explicitly
accepted limitation. Known hook frames still reject; missing source/phase
frames and identifiable unsupported configurations return
`TDD_JEST_PHASE_UNSUPPORTED`.
